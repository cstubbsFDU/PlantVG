Plant Voxel Generator (PlantVG)

PlantVG is a custom MATLAB-based computational tool designed to generate fully three-dimensional (3D) voxel finite element models of herbaceous stem cellular microstructure using only a pair of 2D optical microscopy or computed tomography (CT) slices (transverse and longitudinal).

For example files, see the "Examples" folders of input slices and output voxel meshes.
